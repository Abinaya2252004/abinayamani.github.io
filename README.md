# Abinaya M — Portfolio Site

Personal portfolio for QA / software testing job applications.
Single-file site: `index.html` (no build step, no dependencies).

## How to deploy (GitHub Pages, free)

1. Log in to github.com (account: **abinayamani**)
2. Click **+** (top right) → **New repository**
3. Repository name must be exactly: `abinayamani.github.io` → set **Public** → **Create repository**
4. On the new repo page, click the **"uploading an existing file"** link
5. Drag `index.html` AND `photo.jpg` into the upload box → **Commit changes**
6. Wait 2–3 minutes, then open **https://abinayamani.github.io** — the site is live

## Changing the photo later

Upload a new square photo named exactly `photo.jpg` to the same repo
(**Add file → Upload files**) and it replaces the old one.

## Editing later (no laptop tools needed)

Open the repo on github.com → click `index.html` → pencil icon (Edit) →
change text → **Commit changes**. The live site updates in ~1 minute.
To add a new project, copy one whole `<div class="card"> ... </div>` block
inside the Projects section and edit the text.
